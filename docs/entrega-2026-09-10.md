## Limites explícitos

- O usuário confirmou pelo Lovable o resultado `PASS: RLS, IDOR, balances, journal reversal, imported overrides` após o reparo do ledger. Isso valida os cenários do script SQL no ambiente utilizado. Permanecem pendentes a cadeia completa em banco limpo, a conferência do histórico de migrations, a regeneração dos tipos e a sincronização real repetida. Instruções em `supabase-lovable-2026-09-10.md`.
- A rentabilidade exibida no resumo é bruta e não realizada. Uma estimativa líquida consolidada exige custo fiscal, data de aquisição, taxas e tributação por posição; não foi inventada a partir de dados incompletos. Simulações líquidas existentes dos produtos de renda fixa continuam disponíveis.
- Fluxo de caixa usa no máximo 1.000 transações e avisa quando a amostra atinge esse limite. Não inclui transferências, investimentos ou transações pendentes.
- Contas de investimento são consideradas o saldo consolidado da carteira, evitando somar novamente as posições. Carteiras híbridas devem reconciliar o vínculo entre contas e posições antes de usar uma soma por posição como patrimônio oficial.
- Histórico patrimonial começa com observações reais; variações sem meses comparáveis aparecem como indisponíveis.
- O teste do navegador intercepta a API com fixtures; não prova funcionamento do provedor real nem RLS.
- Medidas de duração/erro HTTP já existentes foram mantidas e o fluxo Open Finance recebeu eventos de resultado/duração. Indicadores de adoção e abandono requerem acompanhamento após publicação.

```sh
npm test

```
